# 运维工单系统 操作手册（内测版 0.2.0）

- 版本：0.2.0（基于 `feature/ticket-work-hours`，提交 152fbfb；登录验证特性位于 `feature/login-verification`）
- 适用对象：内部测试同事（客户提报人 / 运维处理人 / 运维主管 / 管理员）
- 安装包：`TicketReport-Setup-0.2.0.exe`（内置 Node 运行时与演示数据，测试机无需安装 Node）

---

## 1. 安装与启动

1. 双击 `TicketReport-Setup-0.2.0.exe`。
2. 按向导下一步；安装目录默认为 `%LOCALAPPDATA%\Programs\TicketReport`，无需管理员权限。
3. 保持勾选“创建桌面快捷方式”，完成安装。
4. 双击桌面“运维工单系统”，程序在后台启动，几秒后自动打开浏览器。

- 访问地址：<http://127.0.0.1:3210>
- 首次启动会自动把内置演示库复制为正式库，直接可登录体验。
- 关闭浏览器不会停止服务；需要停止时双击开始菜单「运维工单系统 停止服务」（或安装目录下的 `stop.cmd`）。
- 卸载：Windows 设置 → 应用 → 运维工单系统 → 卸载。

> 若浏览器没有自动打开，手动访问上面的地址；仍打不开时查看
> `%LOCALAPPDATA%\TicketReport\logs\server.err.log`。

## 3. 建议体验路线

1. 用 `alice@acme.com` 提交一张工单；
2. 退出，用 `agent2@example.com` 打开该工单，点击“领取工单”（跨组领取）；
3. 处理并填写工时 → 提交处理结果；
4. 用管理员账号在“统计报表”查看关闭来源与工时；
5. 用 `alice@acme.com` 确认已解决关闭，再用运维账号体验收藏与关联。

## 4. 客户提单（提报人）

1. 使用客户账号登录，左侧菜单选择“提交工单”。
2. 填写：
   - 标题：5–100 字，简要描述问题；
   - 分类：决定默认处理组；
   - 优先级：P1（紧急）～P4（低）；
   - 问题描述：至少 10 字，支持富文本、粘贴截图；
   - 附件：可选，最多 5 个，单文件不超过系统设置上限（默认 20MB）。
3. 点击“提交工单”，工单进入“待受理”。
4. 在工单详情可查看处理进度、公开评论、附件；待受理阶段可“编辑”或“撤回工单”。
5. 运维提交处理结果后，提报人可“确认已解决”或“反馈未解决”。

> 运维侧账号也可以在“提交工单”页选择“代客户提单”或“内部工单”。

## 5. 运维处理（处理人 / 运维主管 / 管理员）

### 5.1 查看与筛选

- 左侧“工单列表”支持按编号/标题、状态、优先级、分类、时间范围筛选。
- 列表行首的星标为收藏标记；勾选“只看我收藏”可过滤本人收藏的工单。
- 处理人可以看到：指派给自己的工单、本组工单，以及所有尚未认领的待受理工单。

### 5.2 领取工单（含跨组）

1. 打开状态为“待受理”且“未分配”的工单，页头会出现高亮的“领取工单”按钮。
2. 任何运维侧账号（处理人、运维主管、管理员）都可以领取，不限原处理组。
3. 领取后工单进入“处理中”，处理人为当前账号。
4. 若领取人不在原处理组，页面会提示“可以跨组领取”，时间线记录一条“跨组领取”事件，备注原处理组，便于追溯。
5. 工单列表的“操作”列也提供快捷“领取”。

### 5.3 处理与评论

- 详情页底部可发布“公开评论”（客户可见）或“内部备注”（仅运维可见），支持附件与图片。
- 处理完成后点击“提交处理结果”，填写处理结果，工单进入“待提报人确认”。
- 需要换人处理时，处理人可“转派”，主管/管理员可“改派”。

### 5.4 填写处理工时

- 工单在“处理中 / 待提报人确认 / 已关闭”状态时，详情页“处理工时”右侧出现“填写”或“修改”。
- 支持 0–999.9 小时，保留一位小数，例如 `2.5`。
- 修改会写入工单时间线；报表“工时合计”和“处理人工作量”会同步统计。

### 5.5 关闭工单与关闭来源

关闭有三条路径，系统分别记录来源，报表分列统计：

| 操作人 | 场景 | 按钮 | 记录来源 |
| --- | --- | --- | --- |
| 客户提报人 | 待提报人确认 | 确认已解决 | 提报人确认关闭 |
| 处理人 / 运维主管 / 管理员 | 待提报人确认 | 关闭工单（可填关闭说明） | 处理人关闭 |
| 运维主管 / 管理员 | 处理中、待提报人确认 | 强制关闭（必填原因） | 管理员强制关闭 |

- 详情页“关闭来源”字段展示本单的关闭方式。
- “统计报表 → 关闭来源”卡片分别统计上述三类数量。
- 关闭后客户可在“重开时限”（默认 7 天）内重开工单。

### 5.6 收藏工单

- 详情页右上角“收藏 / 已收藏”按钮可收藏或取消收藏。
- 收藏是个人数据，不影响其他同事。
- 工单列表点击星标也可快速收藏；收藏行会高亮显示；勾选“只看我收藏”筛选。

### 5.7 关联工单

1. 详情页“关联工单”卡片点击“添加关联”。
2. 输入关键词搜索工单，选择后确认，即可建立双向关联。
3. 关联列表可直接跳转对方工单，点击“解除”可取消关联。
4. 权限规则：
   - 只能关联自己有权查看的工单；
   - 客户账号只能看到本企业范围内的关联工单，无法通过关联访问其他企业工单；
   - 越权查看/解除关联会被接口拒绝。

## 6. 管理端（管理员）

左侧“系统管理”包含：客户企业、账号管理、分类与处理组、系统设置、审计日志。

### 6.1 新建客户企业

1. 进入“客户企业”，点击“新建企业”。
2. 填写企业名称、简码（唯一，如 `HD`）、联系人、联系电话、备注。
3. 保存后即可在“账号管理”中为该企业邀请员工。
4. “停用企业”后该企业员工无法登录，历史工单只读保留；可随时重新启用。

### 6.2 邀请账号与调整角色

1. 进入“账号管理”，点击“邀请 / 新建账号”。
2. 选择角色：提报人 / 处理人 / 运维主管 / 管理员。
   - 提报人必须选择所属企业；
   - 运维角色可选所属处理组。
3. 填写姓名、邮箱、电话后点击“发送邀请”。
   - 未配置 SMTP 时邀请邮件只写入本地 outbox，可在“系统设置”查看；
   - 也可在账号列表点击“重发邀请”。
4. 调整角色：在账号列表“角色”列直接切换，确认后立即生效。
5. 客户端提报人只能看到本企业工单，运维角色按组与指派关系查看。

### 6.3 重置密码与强制改密

- 管理员在“账号管理”点击“重置密码”，确认后：
  - 密码恢复为初始密码 `Passw0rd!`（弹窗会显示）；
  - 该账号现有登录会话立即失效；
  - 该账号已信任的设备与未完成的登录验证一并失效；
  - 账号被标记“待改密”，下次登录必须修改密码后才能使用其他功能。
- 用户自助改密：登录后右上角“个人设置”可修改密码。
- 忘记密码：登录页“忘记密码”输入邮箱，系统发送重置链接（需配置 SMTP；未配置时链接写入 outbox）。

### 6.4 分类与处理组

- “分类与处理组”可新增/编辑工单分类，并为分类指定默认处理组。
- 处理组可维护名称、说明与成员（主管可管理本组成员）。
- 客户提单时按分类自动进入默认处理组；运维可改派/转派。

### 6.5 系统设置

- 站点名称、工单重开时限（天）、单附件大小上限（MB）、邮件通知开关。
- 登录验证方式（滑块 / 邮件验证码 / TOTP）、信任设备天数、是否强制运维账号绑定 TOTP，详见第 7 章。
- “邮件 Outbox”展示最近 50 封邮件及状态：
  - `SENT` 已发送；`PENDING` 排队中；`FAILED` 发送失败；
  - `SKIPPED_NO_SMTP` 未配置 SMTP，仅入库未发送。

## 7. 登录验证

登录采用「密码 + 二次验证」两步：密码校验通过后不会立即签发令牌，必须完成当前验证方式才可登录。
验证方式在“系统管理 → 系统设置 → 登录验证”中三选一，**切换后立即生效**，每次切换都会写入审计日志。

### 7.1 三种方式对比

| 方式 | 适用场景 | 说明 |
| --- | --- | --- |
| 滑块验证（默认） | 内网、无邮件环境 | 自研图形滑块，不依赖第三方服务 |
| 邮件验证码 | 已配置 SMTP | 6 位验证码发送到账号邮箱，可信任设备免验证 |
| Google 验证器（TOTP） | 安全要求较高 | 标准 RFC 6238 动态码，支持恢复码与强制绑定 |

### 7.2 滑块验证

- 登录页拖动拼图块对齐缺口，松手即提交。
- 服务端签发一次性票据，2 分钟内有效、最多尝试 3 次，校验后立即作废，防止重放。
- 位置不正确可点击“换一张”获取新图；票据过期需重新输入密码登录。

### 7.3 邮件验证码

- 密码通过后自动向账号邮箱发送 6 位验证码，10 分钟内有效。
- 发送频率与次数：60 秒内不可重发，同一登录最多发送 5 次；连续输错 5 次本次验证作废，需重新登录。
- 勾选“信任此设备”后签发信任设备凭证，默认 7 天内免验证；天数可在“系统设置 → 登录验证”中调整为 1–30 天。
- 个人设置“信任设备”可查看设备、IP、最近使用时间与有效期，并可单独撤销或全部撤销。
- 修改密码、管理员重置密码后，所有信任设备立即失效。
- 未配置 SMTP 时验证码只写入本地 outbox，登录页会直接显示验证码，**仅限内测使用**；生产请先配置 SMTP（见第 9 章）。

### 7.4 Google 验证器（TOTP）

- 绑定：个人设置 → 登录验证器 → “绑定验证器”，用 Google Authenticator / Microsoft Authenticator 扫描二维码（或手动输入密钥），输入 6 位动态码启用。
- 启用时一次性展示 10 个恢复码，请离线保存；每个恢复码只能使用一次，登录页勾选“使用恢复码”即可替代动态码。
- 同一动态码不可重复使用（防重放）；验证器时间需与服务器保持同步。
- 管理员可在“系统设置 → 登录验证”开启“强制运维账号绑定 TOTP”：未绑定的运维账号登录时必须先完成绑定。
- TOTP 模式下未绑定且未强制的账号会回退为滑块验证，避免账号被锁死。
- 管理员在“账号管理”对已绑定账号点击“重置 TOTP”，会清空密钥与恢复码并写入审计；该用户下次登录需重新绑定。

### 7.5 与密码安全流程的配合

- 密码错误仍按原规则限流：同一账号 15 分钟内连续 5 次密码错误将暂时锁定。
- 二次验证失败按账号额外限次：15 分钟内累计 10 次失败将暂时拒绝验证。
- 强制改密：二次验证通过后仍会进入强制改密流程，改密前无法调用其他业务接口。
- 重置密码令牌（忘记密码）与登录验证互不影响；密码重置成功后旧会话、信任设备和未完成的登录验证全部失效。

## 8. AI 问答助手

### 8.1 使用方式

- 左侧菜单进入「AI 助手」为完整对话页；也可点击右下角悬浮按钮，在抽屉内快速提问。
- 输入问题后按 Enter 发送（Shift+Enter 换行）。回答下方会列出「参考来源」，点击标签可查看引用片段，外部知识库条目可跳转原文。
- 对话按账号保存，可在左侧列表切换历史对话、删除对话；同一企业的不同账号互不可见，客户账号只能检索到公开知识，不会看到其他企业内容。
- 管理员尚未启用或未配置大模型时，页面会给出明确提示，不会报错；历史对话仍可查看。

### 8.2 管理员配置

「系统管理 → AI 问答」包含三个页签：

| 页签 | 内容 |
| --- | --- |
| 大模型 | 启用开关、Base URL（OpenAI 兼容）、API Key、模型名、温度、超时、TopK、每用户每分钟限流、单条问题字数、携带历史条数 |
| 知识库 | 知识来源三选一：内置 FAQ / 外部知识库（HTTP）/ 内部知识库（预留占位）；外部知识库可配置接口地址、Key、超时、鉴权头、请求模板与响应字段映射 |
| FAQ 管理 | 新增、编辑、删除、批量导入问答；可设置「公开 / 仅运维内部」与所属企业（留空为全局） |

说明：

- API Key 使用 AES-256-GCM 加密存储，保存后前端只显示「已配置」，不会回显明文；建议单独设置环境变量 `AI_SECRET_KEY` 作为加密密钥。
- 所有配置变更、FAQ 增删改与导入都会写入审计日志；密钥类字段只记录是否变更，不记录明文。
- 外部知识库请求模板支持变量：`{{query}}`、`{{topK}}`、`{{enterpriseId}}`、`{{scope}}`、`{{userId}}`；响应映射中 `itemsPath` 支持点路径（如 `data.items`）。
- 外部知识库异常或无结果时自动回退内置 FAQ；「内部知识库（预留占位）」遵循同一契约但不返回内容，后续接入无需改业务代码。
- 批量导入格式：每条以 `Q: 问题` / `A: 答案` 书写，条目之间空一行，单次最多 200 条。

### 8.3 上报为工单（设计预览）

AI 回答下方的「上报为工单」按钮当前仅展示交互方案与接口契约，**本版本未实现，不会创建工单**。后续版本将支持由大模型从会话上下文生成工单草稿（标题、描述、分类、优先级），用户编辑确认后再通过现有「提交工单」接口创建。

## 9. 邮件 SMTP 配置

程序通过环境变量读取 SMTP。推荐使用数据目录下的配置文件，升级安装不会覆盖：

1. 打开 `%LOCALAPPDATA%\TicketReport`，把安装目录下的 `config.env.sample` 复制为 `config.env`。
2. 取消注释并填写（等号两侧不要留空格，值不要加引号）：

```ini
SMTP_HOST=smtp.exmail.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=no-reply@your-domain.com
SMTP_PASSWORD=your-password
SMTP_FROM=运维工单系统 <no-reply@your-domain.com>
```

3. 双击 `停止服务.cmd`，再重新双击桌面图标启动。
4. 管理员登录“系统设置”，确认提示变为“SMTP 已配置，邮件将实际投递”。
5. 触发一次评论/状态变更，在“邮件 Outbox”确认状态为 `SENT`。

说明：

- `SMTP_SECURE=true` 用于 465 端口（SSL）；587 端口一般用 `false`（STARTTLS）。
- 系统设置中的“开启邮件通知”是总开关，关闭后所有邮件都不发送。
- 未配置 SMTP 时系统仍可正常使用，邮件只写入 outbox，不会真实投递。

## 10. 数据备份与恢复

数据都在 `%LOCALAPPDATA%\TicketReport`：

| 内容 | 路径 |
| --- | --- |
| 数据库 | `data\app.db` |
| 附件 | `uploads\` |
| 日志 | `logs\` |
| 用户配置 | `config.env`（可选） |

备份：

1. 双击开始菜单「运维工单系统 停止服务」（或安装目录下的 `stop.cmd`）；
2. 复制整个 `%LOCALAPPDATA%\TicketReport` 目录到备份位置（至少包含 `data\app.db` 与 `uploads\`）。

恢复：

1. 停止服务；
2. 把备份的 `app.db` 覆盖回 `%LOCALAPPDATA%\TicketReport\data\app.db`，附件放回 `uploads\`；
3. 重新启动程序。

> 数据库升级或切换空库前，程序会自动在 `data` 目录生成 `app.db.bak-时间戳` 备份。

## 11. 切换成空库（仅保留管理员/分类/处理组）

适用场景：正式内测前清空演示数据，或需要重新开始时。

方式一（推荐）：双击开始菜单「运维工单系统 切换空库」（或安装目录下的 `switch-to-base.cmd`），输入 `YES` 确认。脚本会先停止服务、备份当前数据库，再替换为空库模板。

方式二：手动操作

1. 停止服务；
2. 备份后删除 `%LOCALAPPDATA%\TicketReport\data\app.db`；
3. 把安装目录 `data\base.db` 复制为 `%LOCALAPPDATA%\TicketReport\data\app.db`；
4. 启动程序。

空库仅包含：管理员 `admin@example.com / Admin123!`、3 个工单分类、2 个处理组，无演示企业与工单。

> 研发环境中对应的命令为 `npm run seed:base`。

## 12. 常见问题

### 12.1 端口 3210 被占用

1. 打开 `%LOCALAPPDATA%\TicketReport`，把 `config.env.sample` 复制为 `config.env`；
2. 写入 `PORT=3211`（或其他空闲端口）；
3. 重新启动，访问 `http://127.0.0.1:3211`。

也可用 Windows“资源监视器”或 `netstat -ano | findstr :3210` 找到占用进程后处理。

### 12.2 Windows SmartScreen 拦截

安装包为内部未签名版本，SmartScreen 可能提示“Windows 已保护你的电脑”。点击“更多信息 → 仍要运行”即可。

### 12.3 双击图标后浏览器没反应

- 等待 5–10 秒后刷新 <http://127.0.0.1:3210>；
- 查看 `%LOCALAPPDATA%\TicketReport\logs\server.err.log`；
- 确认端口未被占用，必要时修改 `config.env` 的 `PORT`。

### 12.4 升级后登录异常或页面报错

- 0.2.0 启动时会自动升级旧版数据库（升级前生成 `app.db.bak-时间戳` 备份）；
- 如仍异常，停止服务后查看 `logs\migrate.log`；
- 演示数据可在备份后删除 `data\app.db` 重新生成。

### 12.5 卸载

Windows 设置 → 应用 → 运维工单系统 → 卸载。卸载不会删除 `%LOCALAPPDATA%\TicketReport` 数据目录；如需彻底清理，请手动删除该目录。

### 12.6 测试机需要装 Node 吗

不需要。安装包已内置 Node 运行时与全部依赖。
